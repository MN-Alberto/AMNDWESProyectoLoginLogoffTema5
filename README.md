# Aplicación Login / Logoff – DWES (Tema 5)

Aplicación desarrollada para el **Tema 5 de la asignatura Desarrollo Web en Entorno Servidor (DWES)**, centrada en la **gestión de sesiones**, **autenticación de usuarios** y **cierre de sesión (logoff)** mediante PHP.

---

## 🎯 Objetivo del proyecto

El objetivo de esta aplicación es poner en práctica:

- Uso de **sesiones en PHP**
- Sistema de **login y logout**
- Control de acceso a páginas privadas
- Validación de credenciales contra base de datos
- Protección de rutas mediante sesión activa

---

## 🛠️ Tecnologías utilizadas

- **PHP**
- **MySQL / MariaDB**
- **HTML5**
- **CSS3**
